Cardinal A3

A personal assistant for a fictional schedule, test inbox and synthetic project deadlines.

Cardinal A3 is Karthik Venugopal’s CSCI 599 Assignment 3 project. It combines a cloud-hosted OpenClaw agent with local Gemma inference on the operator’s laptop.

What the assistant does

  • Reads a dedicated Google Calendar to find conflicts and available work time.
  • Summarizes a dedicated test Gmail inbox and drafts replies. Every email send requires explicit human review of the exact recipient, subject and body.
  • Delivers morning briefings, meeting or deadline alerts, and end-of-day recaps to the configured owner’s Telegram chat.
  • Searches public sources, retrieves weather, and suggests calendar-aware work blocks.
  • Stores synthetic preferences and deadlines for continuity across sessions.

How Google access is used

The application requests Gmail read access, Gmail send access, and access to app-created calendars. It connects only the operator’s dedicated classroom test account and uses made-up email and calendar content. See the privacy and data-use notice for storage, model processing and access details.

Who can use it

This is a restricted classroom prototype, with access provided privately to the operator and authorized graders. These public pages provide information about the project; they do not provide public access to the running assistant or its accounts.

Read the classroom-use terms. For questions about this project or its data, contact csci599assignment3@gmail.com.
